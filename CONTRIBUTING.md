# Contributing to AEP AI

Thank you for helping improve the AEP AI open-source ecosystem.

## Before opening a change

1. Search existing issues and open an issue for protocol or behavior changes.
2. Keep the change inside the repository's documented scope.
3. Never include credentials, private infrastructure, security response
   procedures, signed payment payloads, or non-public economic parameters.
4. Add or update tests and documentation.

## Development workflow

Fork the repository, create a focused branch, run its test and build workflows,
then open a pull request describing motivation, compatibility impact, and
validation performed. All commits must be your own work or appropriately
licensed for contribution under Apache-2.0.

## Review

Maintainers review correctness, compatibility, tests, security boundaries, and
documentation. Approval does not imply deployment to the hosted AEP network.
